# GripApps browser runtime

Canonical bundle: `public/gripapps/runtime.js` (vendored into each build as `vendor/gripapps/runtime.js`).

## Load order (`index.html`)

1. Load shared runtime from `https://lilgrip.com/gripapps/runtime.js?v=1`
2. On CDN failure, load `./vendor/gripapps/runtime.js`
3. Load `./app.grip.js` (ES module) which sets `globalThis.__GRIP_APP__`
4. Call `globalThis.GripApps.start(rootElement)`

Boot HTML is generated by `gripapps/gripc/src/boot-html.ts`.

## Host API

```js
globalThis.GripApps.start(document.getElementById("grip-root"));
```

| Member | Meaning |
| --- | --- |
| `GripApps.start(rootEl)` | Mount app into `#grip-root` |
| `GripApps._apiVersion` | IR/runtime contract version (currently `1`) |

Compiled apps expose IR on `globalThis.__GRIP_APP__` before `start` runs.

## Themes

Theme id comes from `meta.theme`. Named presets (CSS variables: background gradient, surface, accent, text):

- `lilgrip_default` — Catppuccin-inspired lilgrip palette
- `neon_lagoon`, `barn_night`, `candy_arcade`, `deep_space`

Scenes may set `vibe <preset>` to override atmosphere for that scene. Unknown themes fail `gripc check`.

## Scene motion

Scenes may declare `motion bounce|float|pulse|none`. The runtime adds `grip-motion-*` classes on the scene host. When `prefers-reduced-motion: reduce`, motion animations are skipped (particles and other heavy effects are also toned down).

## Behavior notes

- Scene stack supports `goto` / `back` navigation
- `prefers-reduced-motion: reduce` tones down heavy motion (e.g. particles)
- `raw_module` scripts load from paths under `./raw/` only. Paths containing `..` are rejected. The URL is `new URL(path, document.baseURI)` (page-relative). A missing or non-function export shows a toast.
- `grid`, `hero`, `card`, `modal`, and `tabs` render as visible containers with their children. `toggle`, `slider`, `timer`, and scene-level `toast` are rejected by `gripc check` and are not interactive.
- After a scene change, previously mounted raw-module DOM is reattached to the slot. A shell slot is created only when the scene has no `raw_slot` with that name.
- Boot `index.html` uses `meta.title` for `<title>`, puts the handle on `data-grip-handle`, and shows an error if the CDN runtime, vendored runtime, or `app.grip.js` fails to load.
- Uncaught errors show an in-app boundary with retry
