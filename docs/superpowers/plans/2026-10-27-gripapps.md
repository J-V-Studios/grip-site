# GripApps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship GripApps — AI-first GripLang + `gripc` cross-compiler + shared/vendored runtime + specialized agent skill — so every new lilgrip community page is extremely robust and cheap for Cursor agents to author.

**Architecture:** Agents write `app.grip` (closed-vocabulary GripLang). `gripc` validates and emits `app.grip.js` + boot `index.html` + `manifest.json` fields, and vendors `public/gripapps/runtime.js` into each handle. The browser loads shared runtime with vendored fallback, renders scenes with error boundaries, and supports a sandboxed `raw/` escape hatch. The GripApps skill replaces `community-builder` for orchestrator planner/builder runs.

**Tech Stack:** TypeScript + Bun + Vitest (compiler/tests), vanilla JS runtime for GitHub Pages, existing community path-guard CI, Zod where useful for emitted schema checks.

## Global Constraints

- Sandbox writes only under `public/community/<handle>/**` for community agents.
- Community agents must never modify `public/gripapps/**` (core runtime); they only vendor a copy.
- No `eval` of visitor text or generated strings as code.
- State in GripLang must be JSON-serializable only.
- Runtime load order: shared `https://lilgrip.com/gripapps/runtime.js?v=<VERSION>` then `./vendor/gripapps/runtime.js`.
- New community builds use GripApps only; do not force-rewrite existing live HTML pages.
- GripLang is AI-first: closed vocabulary, verbose keywords, actionable diagnostics.
- Prefer TDD: failing Vitest → implement → pass → commit per task.
- Root test runner remains `bun run test` (vitest); include `tests/unit/gripapps/**/*.test.ts`.

**Interfaces:**
- Consumes: `globalThis.__GRIP_APP__` IR from Task 3
- Produces: `globalThis.GripApps.start(rootEl: HTMLElement): void`
- Dual-load is the responsibility of `index.html` from `renderBootHtml`:
  1. Try script `https://lilgrip.com/gripapps/runtime.js?v=VERSION`
  2. `onerror` → load `./vendor/gripapps/runtime.js`
  3. Then `import('./app.grip.js')` or classic script order, then `GripApps.start`

**Runtime must:**
- Read IR; if missing/invalid → show error boundary
- Apply lilgrip_default theme CSS variables on root
- Render current scene; start at first scene
- Handle action steps: `set`, `goto`, `back`, `toast` (toast can be a simple fixed div)
- Honor `prefers-reduced-motion` (disable particles/transitions when set)
- `window.addEventListener('error'/'unhandledrejection')` → boundary with Retry button
